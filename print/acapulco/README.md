# Acapulco print files ✝️

Printed pieces for the Acapulco offer. **Everything printed is bilingual (Spanish + English).**
This folder is NOT published to any website. It's just kept safe in git.

| File | What it is | QR goes to |
|---|---|---|
| `MX-Studio-Card-5x7.pdf` | MX Studio 5×7 card (front logo, back QR). Includes 1/8" bleed. | Main QR → https://go.myjefetech.app/acapulco/ · Small QR → saves Brian's contact (works offline) |
| `Restaurant-Order-Card-Sample.pdf` | Sample business-card pass-out for "Mariscos La Bahía" (made-up) | WhatsApp +52 744 193 0502, "Hola, quiero hacer un pedido" |
| `La-Bahia-Table-Cards-Mesas-1-10.pdf` | Sample 4×6 table cards, Mesas 1–10 | https://go.myjefetech.app/acapulco/la-bahia/?mesa=N |
| `Hotel-Caleta-Room-Cards.pdf` | Sample 4×6 room cards, 101–105 and 201–205 | https://go.myjefetech.app/acapulco/hotel-caleta/?hab=N |

All QR codes were scan-tested before saving (Oct 30, 2026).
